GS Public API Reference

Exhaustive list of methods available on the window.GS object. Each entry includes inputs, outputs, side-effects, and usage guidance.

Core Lifecycle GS.core

Method Inputs Output Effect Use when

Querying GS.query

Method Inputs Output Effect Use when
GS.query.from(entityType?) entityType?: string QueryBuilder No mutation Starting a query scoped to an entity type.
GS.query.where(predicate) predicate: object QueryBuilder No mutation Starting a query with a filter.
GS.query.diff(oldVersionId, newVersionId) oldVersionId: string, newVersionId: string QueryBuilder No mutation Querying differences between versions.
GS.query.shortestPath(fromId, toId) fromId: string, toId: string QueryBuilder No mutation Finding the shortest path between two entities.
GS.query.eq(field, value) field: string, value: any predicate object No mutation Building equality predicate in query expressions.
GS.query.neq(field, value) field: string, value: any predicate object No mutation Building inequality predicate in query expressions.
GS.query.gt(field, value) field: string, value: any predicate object No mutation Building greater-than predicate in queries.
GS.query.lt(field, value) field: string, value: any predicate object No mutation Building less-than predicate in queries.
GS.query.in(field, array) field: string, array: any[] predicate object No mutation Building membership predicate in queries.
GS.query.exists(field) field: string predicate object No mutation Checking field existence in queries.
GS.query.contains(field, value) field: string, value: any predicate object No mutation Checking substring/array containment in queries.
GS.query.matches(field, regexString) field: string, regexString: string predicate object No mutation Applying regex match predicate in queries.
GS.query.expr(type, args) type: string, args: any[] expression object No mutation Composing advanced predicate trees.

QueryBuilder methods (returned by GS.query.*): where(), and(), or(), traverse(), expand(), select(), execute(). These are chainable and do not mutate graph state; execute() emits query.execute and query.result.
