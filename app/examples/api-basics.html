🚀 GraphSense - API Basics

This example demonstrates the core CRUD operations (Create, Read, Update, Delete) using the GS API. Open the browser console (F12) to see detailed logs.

📝 1. Create Entities

Add entities to the graph with metadata:

GS.graph.addEntity({
  id: 'person1',
  type: 'person',
  metadata: { name: 'Alice', role: 'Developer' }
})

🔗 2. Create Relations

Connect entities with relations:

GS.graph.addRelation({
  id: 'rel1',
  type: 'works_on',
  source: 'person1',
  target: 'project1',
  metadata: { since: '2024-01-01' }
})

📖 3. Read Data

Query entities and relations:

// Get specific entity
GS.graph.getEntity('person1')

// Get all entities
GS.graph.getEntities()

// Get entities by type
GS.graph.getEntitiesByType('person')

✏️ 4. Update Entities

Modify existing entity metadata:

GS.graph.updateEntity('person1', {
  name: 'Alice Smith',
  role: 'Senior Developer'
})

🗑️ 5. Delete Data

Remove entities and relations:

GS.graph.removeRelation('rel1')
GS.graph.removeEntity('person1')

💾 6. Export/Import

Serialize and load graph data:

// Export
const data = GS.graph.toJSON()

// Import
GS.graph.fromJSON(data)

🔄 7. Undo/Redo

Navigate through history:

GS.undo()  // Undo last operation
GS.redo()  // Redo undone operation
