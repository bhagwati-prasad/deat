🔍 GraphSense - QueryEngine Examples

Demonstrates powerful graph querying capabilities including filtering, traversal, path finding, and aggregation.

🎯 1. Simple Filtering

Find entities by type and metadata:

// Find all developers
GS.query.findEntities({
  type: 'person',
  filter: e => e.metadata.role === 'Developer'
})

🌐 2. Graph Traversal

Explore connected nodes:

// Find all projects a person works on
GS.query.traverse('person1', {
  direction: 'outgoing',
  relationType: 'works_on',
  maxDepth: 2
})

🛤️ 3. Path Finding

Find paths between two entities:

// Find shortest path
GS.query.findPath('person1', 'org1', {
  maxDepth: 4
})

📊 4. Aggregation

Compute statistics over entities:

// Count entities by type
GS.query.aggregate('count', {
  groupBy: 'type'
})

🔗 5. Relation Queries

Query relations between entities:

// Find all 'works_on' relations
GS.query.findRelations({
  type: 'works_on',
  filter: r => r.metadata.since >= '2024-01-01'
})

🎨 6. Complex Queries

Combine multiple filters and conditions:

// Find active projects with >2 contributors
GS.query.findEntities({
  type: 'project',
  filter: e => {
    const contributors = GS.query.getIncoming(e.id, 'works_on');
    return e.metadata.status === 'active' && 
           contributors.length > 2;
  }
})
