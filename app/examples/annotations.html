📝 GraphSense - Annotations Example

Demonstrates how to add notes, tags, and custom metadata to entities without modifying the underlying graph structure.

📌 1. Adding Notes

Attach rich text notes to entities:

GS.annotations.addNote('repo1', 'Important repository for Q1 release')

🏷️ 2. Adding Tags

Categorize entities with tags:

GS.annotations.addTag('repo1', 'critical')
GS.annotations.addTag('repo1', 'q1-release')

📖 3. Reading Annotations

Get all annotations for an entity:

const annotations = GS.annotations.getAnnotations('repo1')

🔍 4. Searching by Tags

Find entities with specific tags:

const critical = GS.annotations.findByTag('critical')

✏️ 5. Editing Annotations

Update or remove annotations:

GS.annotations.updateNote(noteId, 'Updated content')
GS.annotations.removeTag('repo1', 'old-tag')

💾 6. Annotations Persistence

Annotations survive graph refreshes:

// Annotations persist even when entity metadata changes
GS.graph.updateEntity('repo1', { ...newData })
// Annotations still intact!
